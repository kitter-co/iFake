# Font Key

Type chords how you'd expect for the most part. For example: B13(b9)

But there are some weird things:

- option + 9 makes a natural symbol
- option + q makes the diminished symbol
- option + 8 makes the augmented +
- option + y makes "maj"
- option + e makes "dim"
- option + l makes a double flat
- option + u makes a double flat
- option + g makes a sharp
- option + 
- option + m makes "N.C."
- ' makes "add"
- æ (option + ') makes "aug"
- ¡ (option + 1) makes "alt."
- ; makes "omit"
- . makes "mi"
- , makes "ma" as in a major 7th or something
- option + shift + 9 makes sus (or option + shift + z)
- option + shift + 0 makes the / for 6/9
- å (option a) makes two stacked sharps (like how #9 #5 is often written)
- Á makes 9 with a 5 below
